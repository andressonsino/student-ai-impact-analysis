# student-ai-impact-analysis
EDA and Machine Learning models predicting burnout risk and academic performance based on GenAI usage in 50k students. In spanish.

**Descripción del Proyecto:**

Este repositorio contiene un análisis de minería de datos enfocado en entender cómo el uso de herramientas de Inteligencia Artificial Generativa moldea la educación moderna. A partir de una base de 50.000 registros, el proyecto utiliza Python para realizar limpieza de datos, análisis exploratorio (EDA) y la construcción de algoritmos predictivos. Los objetivos principales incluyen clasificar automáticamente el riesgo de burnout (agotamiento) de los estudiantes y modelar el impacto real de la IA en sus calificaciones académicas.
